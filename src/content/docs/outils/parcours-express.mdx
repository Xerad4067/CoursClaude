Objectif : arriver à ton choix d'option (vers janvier 2027) avec de **vraies bases de développement**, sans t'épuiser. Base indicative : **6 à 7 h par semaine**, découpées en séances de 15 min à 2 h. Ce cours **complète** ton BTS, il ne le remplace pas.

## Ce qui est essentiel pour SLAM… et ce qui peut attendre

| Essentiel avant janvier | Peut attendre |

| **A** Installer et démarrer (6 h) | **E** Scripts Nanos World (34 h) : dès que ton accès est ouvert |
| **B** Lua et logique (24 h) | **F** Mapping (28 h) : en parallèle de E |
| **C** Penser en développeur + Git (16 h) | **G** Projet fil rouge (16 h) |
| **D** Passerelle SLAM : POO, SQL, Web (18 h) | **H** Autonomie et employabilité (6 h) |

## Jalons (un résultat visible toutes les deux semaines)

- **19 oct.** : deux machines prêtes, dépôt GitHub synchronisé, fiche de personnage et ticket de caisse en Lua.
- **2 nov.** : jeu de devinettes jouable dans le terminal, calculateur de salaire.
- **16 nov.** : mini-inventaire, annuaire des métiers en modules, mini boutique (parcours B terminé).
- **30 nov.** : une Pull Request relue et fusionnée, un conflit résolu.
- **14 déc.** : une petite application « boutique » avec classes, base SQLite et page web.
- **28 déc.** : tu sais expliquer variables, fonctions, POO, SQL et Git avec **tes propres projets** sur GitHub.

## Semaine chargée ? Le rythme minimal

<Encadre type="retenir">
**3 séances de 30 minutes par semaine** suffisent à garder le contact. Ordre de priorité : A en entier → B1 à B6 → la partie Git du parcours C → POO et SQL du parcours D. Une semaine à zéro ne casse rien : reprends simplement à ta « prochaine action ».
</Encadre>

## Quand ton accès Nanos World s'ouvre

Entrelace **deux séances de scripts (E) pour une séance de mapping (F)**, en gardant au moins la moitié de ton temps sur A-D jusqu'au 1er janvier.
