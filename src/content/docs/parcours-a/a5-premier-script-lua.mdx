**Pourquoi c'est utile ?** Tout script Nanos World est un fichier Lua. Savoir créer un fichier, l'exécuter et **lire ses erreurs**, c'est la boucle que tu répéteras des milliers de fois.

## Étape 1 · Hello World en Lua (15 min)

1. Dans le terminal :
```powershell
cd ~\Dev\mon-apprentissage
mkdir parcours-a
code parcours-a\bonjour.lua
```
(Si `parcours-a` existe déjà, `mkdir` le signale : ce n'est pas grave.)

2. Dans VS Code, écris et enregistre :
```lua title="parcours-a/bonjour.lua"
-- Mon premier programme Lua
print("Bonjour, j'apprends Lua !")
```
3. Exécute-le :
```powershell
lua parcours-a\bonjour.lua
```
Résultat attendu :
```text
Bonjour, j'apprends Lua !
```

Ligne par ligne :
- `-- Mon premier programme Lua` : un **commentaire**. Tout ce qui suit `--` sur la ligne est ignoré par Lua ; c'est une note pour les humains.
- `print("...")` : `print` est une **fonction** fournie par Lua qui affiche ce qu'on lui donne entre parenthèses, puis passe à la ligne. Le texte entre guillemets est une **chaîne de caractères** (*string*).

<Encadre type="astuce">
Le terminal intégré de VS Code (**Terminal → Nouveau terminal**) s'ouvre directement dans le dossier du projet : tu écris en haut, tu exécutes en bas, sans changer de fenêtre.
</Encadre>

## Étape 2 · print, commentaires et un peu de collage (15 min)

`print` accepte **plusieurs valeurs** séparées par des virgules : il les affiche sur la même ligne, séparées par une **tabulation**. Il sait aussi afficher des nombres et le résultat d'un calcul :

```lua title="essais.lua"
print("Argent :", 150)   -- deux valeurs : un texte et un nombre
print(10 + 5)            -- affiche 15 : Lua calcule d'abord
print("Je code en " .. _VERSION)  -- .. colle deux textes
```

- `..` (deux points) **colle** deux textes bout à bout (on l'étudiera en détail au module B2).
- `_VERSION` est une valeur fournie par Lua qui contient sa version : ici `Lua 5.4`.

Les **commentaires sur plusieurs lignes** s'écrivent entre `--[[` et `]]` :

```lua title="commentaires.lua"
--[[
  Ce bloc entier est ignoré par Lua.
  Pratique pour désactiver plusieurs lignes d'un coup.
]]
print("Seule cette ligne s'affiche")
```

## Étape 3 · Lire une erreur Lua (15 min)

Écris volontairement une faute de frappe :

```lua title="erreur.lua"
print("Ligne 1")
prnt("Ligne 2")
```

Exécute `lua erreur.lua`. Lua 5.4 affiche (vérifié) :

```text
Ligne 1
lua: erreur.lua:2: attempt to call a nil value (global 'prnt')
stack traceback:
        ...
```

Comment le lire :
1. `Ligne 1` s'est affichée : Lua exécute **dans l'ordre** et s'arrête à la première erreur.
2. `erreur.lua:2:` : le **fichier** et la **ligne** (2).
3. `attempt to call a nil value (global 'prnt')` : « tentative d'appeler une valeur nil (la variable globale `prnt`) ». Traduction : *tu appelles une fonction `prnt` qui n'existe pas*.
4. Le `stack traceback` (la pile d'appels) sert pour les gros programmes : ignore-le pour l'instant.

Autre erreur classique, le guillemet oublié : `print("Bonjour)` donne une erreur de syntaxe **avant même** d'exécuter la moindre ligne (le message parle de chaîne non terminée, *unfinished string*).

<Encadre type="retenir">
Une erreur Lua = **fichier : ligne : message**. Va à la ligne indiquée, et si tu n'y vois rien, regarde **la ligne juste au-dessus**.
</Encadre>

## Étape 4 · Chercher, lire l'anglais, demander à une IA (20 min)

### Chercher efficacement
- Copie le **message exact** (sans le nom de ton fichier) et ajoute le langage : `lua "attempt to call a nil value"`.
- Préfère les sources **officielles** (manuel Lua 5.4, docs Nanos World), puis les réponses récentes.
- Vérifie la **version** : beaucoup de tutoriels « Lua » parlent de Roblox (Luau) ou de Lua 5.1.

### Lire une documentation en anglais
1. Lis d'abord les **titres** et les **exemples de code** : le code est international.
2. Utilise le traducteur de ton navigateur (clic droit → **Traduire en français**), mais **garde les mots techniques en anglais** : ce sont ceux des messages d'erreur.
3. Note les mots nouveaux dans ton journal (lexique perso). Le [glossaire](/outils/glossaire/) donne déjà les principaux.

### Une IA comme tuteur
Utilise les [prompts modèles](/outils/ia-tuteur/) : contexte, code, erreur exacte, et la consigne **« ne me donne pas la solution, donne-moi un indice »**. Vérifie toujours ce qu'elle affirme : elle peut inventer des fonctions.

### Et Claude Code ?
C'est **optionnel** (abonnement payant requis). Si tu l'utilises, ce dépôt contient déjà un fichier `CLAUDE.md` (ton profil, les règles, les commandes) et des **permissions raisonnables** dans `.claude/settings.json` (il demande avant `git push`, les installations et les suppressions). Installation et réglages : [tutoriel, section 12](/installer/tutoriel/#12-claude-code-optionnel).

## Récapitulatif

- Créer `fichier.lua` dans VS Code, l'exécuter avec `lua fichier.lua`.
- `print` affiche ; plusieurs valeurs séparées par des virgules → tabulation ; `--` et `--[[ ]]` pour commenter ; `..` colle du texte.
- Erreur = **fichier : ligne : message** ; une erreur de syntaxe empêche tout le fichier de s'exécuter.
- Chercher : message exact + `lua`, sources officielles, attention à la version. IA : indices d'abord.

## Je suis bloqué, que faire ?

`lua` n'est pas reconnu → [tutoriel, section 8.4](/installer/tutoriel/#84-erreurs-fréquentes). `cannot open fichier.lua` → tu n'es pas dans le bon dossier (`pwd`, `dir`). Une erreur que tu ne comprends pas → [Dépannage, section Lua](/outils/depannage/) puis le [prompt modèle n°2](/outils/ia-tuteur/).
