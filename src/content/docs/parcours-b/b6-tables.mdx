**Pourquoi c'est utile ?** Un inventaire, la liste des joueurs connectés, la fiche d'un joueur (nom, argent, métier) : tout cela se range dans des **tables**. C'est LA structure de Lua.

## Étape 1 · Les listes (25 min)

<Encadre type="analogie">
Une **liste** est un **casier numéroté** : case 1, case 2, case 3… En Lua, la numérotation commence à **1**.
</Encadre>

```lua title="b6/liste.lua"
local inventaire = { "pain", "eau", "lampe" }
print(inventaire[1])              --> pain
print(#inventaire)                --> 3 : nombre d'éléments
table.insert(inventaire, "corde") -- ajoute à la fin
print(inventaire[#inventaire])    --> corde : le dernier
print(inventaire[10])             --> nil : case vide
```

<FinEtape id="B6-e1" titre="Les listes" victoire="tu ranges et lis des éléments dans une liste." prochaine="parcourir une liste (étape 2)." />

## Étape 2 · Parcourir avec ipairs (20 min)

```lua title="b6/parcourir.lua"
for i, objet in ipairs(inventaire) do
  print(i .. ". " .. objet)
end
```

`ipairs` donne, à chaque tour, la **position** `i` et la **valeur** `objet`, dans l'ordre 1, 2, 3… Si tu n'as pas besoin de la position, la convention est de l'appeler `_` : `for _, objet in ipairs(inventaire) do`.

<FinEtape id="B6-e2" titre="Parcourir une liste" victoire="tu affiches tous les éléments d'une liste avec une boucle." prochaine="les dictionnaires (étape 3)." />

## Étape 3 · Les dictionnaires (25 min)

Une table peut aussi associer des **clés** (des noms) à des valeurs : c'est une **fiche**.

```lua title="b6/fiche.lua"
local joueur = { nom = "Sam", argent = 1500, metier = "taxi" }
print(joueur.nom)                 --> Sam
joueur.argent = joueur.argent + 100
print(joueur["argent"])           --> 1600 (autre écriture équivalente)
joueur.permis = true              -- ajouter une clé
joueur.metier = nil               -- supprimer une clé

for cle, valeur in pairs(joueur) do
  print(cle, valeur)              -- ordre NON garanti !
end
```

<Encadre type="piege">
`pairs` parcourt toutes les clés **dans un ordre imprévisible**. Si l'ordre compte (affichage), range les clés dans une liste et trie-la avec `table.sort` (tu le feras dans le mini-projet).
</Encadre>

<FinEtape id="B6-e3" titre="Les dictionnaires" victoire="tu manipules une fiche de joueur avec des clés." prochaine="les outils table et le piège des références (étape 4)." />

## Étape 4 · Outils `table` et références (25 min)

| Fonction | Effet |
|---|---|
| `table.insert(t, v)` | ajoute `v` à la fin |
| `table.insert(t, pos, v)` | insère `v` à la position `pos` |
| `table.remove(t)` / `table.remove(t, pos)` | retire (et renvoie) le dernier élément / celui de la position |
| `table.sort(t)` | trie la liste (ordre alphabétique ou croissant) |
| `table.concat(t, ", ")` | colle les éléments en un texte |

**Une table n'est pas copiée** quand tu l'affectes à une autre variable : les deux noms désignent **la même** table.

```lua title="b6/reference.lua"
local a = { 1, 2, 3 }
local b = a          -- b et a désignent la MÊME table
b[1] = 100
print(a[1])          --> 100
```

<Encadre type="analogie">
Les nombres et les chaînes se **photocopient** ; une table, on en donne **l'adresse**. Deux personnes avec la même adresse vont dans la même maison.
</Encadre>

<FinEtape id="B6-e4" titre="Outils table et références" victoire="tu tries, retires, assembles, et tu connais le piège des références." prochaine="les exercices, puis le mini-inventaire." />

## Erreurs fréquentes

| Symptôme / message | Cause | Solution |
|---|---|---|
| `nil` au premier élément, le dernier manque | Boucle de 0 à #t - 1 (habitude d'autres langages) | En Lua : de 1 à #t |
| `attempt to index a nil value (local 'joueur')` | La table n'existe pas | Crée-la avec `{}` avant |
| `bad argument #1 to 'insert' (table expected, got nil)` | `table.insert` sur une variable vide | Vérifie le nom de la table |
| Affichage dans un ordre différent à chaque fois | `pairs` n'a pas d'ordre | Trie une liste des clés |

<Exercice id="B6-ex07" titre="Défi : compter les ventes" niveau="rouge" dossier="B6/ex07" fichier="ventes.lua">
À partir de la liste des ventes du jour, compte combien de fois chaque produit a été vendu, puis affiche `pain`, `eau`, `lampe` dans cet ordre.

<div slot="indice1">Un dictionnaire `compte` dont les clés sont les produits.</div>
<div slot="indice2">Pour chaque vente : `compte[produit] = (compte[produit] or 0) + 1`.</div>
<div slot="indice3">Pour l'affichage dans un ordre fixe, parcours une liste `{ "pain", "eau", "lampe" }`.</div>
<div slot="solution">Le motif `(t[k] or 0) + 1` est l'un des plus utiles de Lua : compter, cumuler, regrouper.</div>

<Exercice id="B6-ex08" titre="Mini-projet : mini-inventaire" niveau="rouge" type="projet" dossier="B6/ex08" fichier="inventaire.lua">
Un inventaire est un dictionnaire `objet → quantité`. Écris `ajouter(objet, quantite)`, `retirer(objet, quantite)` (refuse s'il n'y en a pas assez, renvoie `true`/`false`, supprime l'objet à 0) et `afficher()` (ordre alphabétique). Puis rejoue le scénario attendu.

<div slot="validation">Retirer une lampe absente affiche un refus sans planter ; l'affichage est trié.</div>
<div slot="indice1">`inventaire[objet] = (inventaire[objet] or 0) + quantite`.</div>
<div slot="indice2">Pour trier : collecte les noms avec `pairs` dans une liste, puis `table.sort`.</div>
<div slot="indice3">Dans `retirer`, compare d'abord la quantité actuelle (`or 0`) avec celle demandée.</div>
<div slot="solution">Ces trois fonctions sont la base de l'inventaire de ton serveur RP (parcours E et G), où il faudra en plus **sauvegarder** les données.</div>
</Exercice>

## Récapitulatif

- Liste : `{ "a", "b" }`, `t[1]`, `#t`, `ipairs`. Dictionnaire : `{ cle = valeur }`, `t.cle`, `pairs` (ordre non garanti).
- `table.insert`, `table.remove`, `table.sort`, `table.concat`.
- Une table est partagée par référence : `b = a` ne copie pas.

## Je suis bloqué, que faire ?

Affiche le contenu d'une table avec une boucle `pairs` pour voir ce qu'elle contient vraiment. Vérifie les bornes de tes boucles (1 à `#t`).
