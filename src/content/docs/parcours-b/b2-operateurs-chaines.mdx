**Pourquoi c'est utile ?** Calculer un salaire, un prix avec une remise, afficher « Sam a 1 650 € » proprement : un serveur roleplay calcule et affiche en permanence.

## Étape 1 · Calculer (20 min)

| Opérateur | Sens | Exemple | Résultat |
|---|---|---|---|
| `+` `-` `*` | addition, soustraction, multiplication | `12 * 3` | `36` |
| `/` | division (toujours décimale) | `10 / 4` | `2.5` |
| `//` | division entière (arrondie vers le bas) | `17 // 5` | `3` |
| `%` | reste de la division (modulo) | `17 % 5` | `2` |
| `^` | puissance (résultat décimal) | `2 ^ 3` | `8.0` |

Priorités : comme en maths, `^` puis `*` `/` `//` `%`, puis `+` `-`. Les **parenthèses** imposent l'ordre : `(2 + 3) * 4` vaut `20`.

<Encadre type="analogie">
`//` et `%` répondent à « 17 bonbons pour 5 enfants » : chacun en a `17 // 5 = 3`, il en reste `17 % 5 = 2`. En RP : combien de pleins d'essence complets avec ton argent, et combien il te reste.
</Encadre>

## Étape 2 · Comparer (20 min)

Une comparaison donne un **booléen** :

```lua title="b2/comparer.lua"
local argent = 1500
print(argent >= 1000)   --> true  (supérieur ou égal)
print(argent == 1500)   --> true  (égal : DEUX signes =)
print(argent ~= 1500)   --> false (différent : ~=)
print("taxi" == "Taxi") --> false (les majuscules comptent)
```

<Encadre type="piege">
`=` **range** une valeur ; `==` **compare**. Et « différent » s'écrit `~=` en Lua (pas `!=` comme dans d'autres langages). Comparer un nombre et une chaîne avec `<` provoque l'erreur `attempt to compare number with string`.
</Encadre>

<FinEtape id="B2-e2" titre="Comparer" victoire="tu sais produire true ou false à partir d'une comparaison." prochaine="coller et mesurer du texte (étape 3)." />

## Étape 3 · Coller, mesurer, convertir (25 min)

```lua title="b2/textes.lua"
local nom = "Sam"
local argent = 1500
print("Bonjour " .. nom .. ", tu as " .. argent .. " €")  -- .. colle ; le nombre est converti
print(#nom)                     --> 3 : # donne la longueur
print(tonumber("250") + 50)     --> 300 : texte → nombre
print(tonumber("abc"))          --> nil : conversion impossible
print(tostring(42) .. "!")      --> 42! : nombre → texte
```

- `..` colle des chaînes (et convertit les nombres en texte au passage) ;
- `#` donne la longueur en **octets** : `#"Sam"` vaut `3`, mais une lettre accentuée compte pour 2 (`#"é"` vaut `2`) car Lua stocke le texte en UTF-8 ;
- `tonumber` renvoie `nil` si le texte n'est pas un nombre : très utile pour vérifier une saisie.

## Étape 4 · La boîte à outils `string` (25 min)

| Fonction | Exemple | Résultat |
|---|---|---|
| `string.upper(s)` / `string.lower(s)` | `string.upper("taxi")` | `TAXI` |
| `string.sub(s, debut, fin)` | `string.sub("garagiste", 1, 4)` | `gara` |
| `string.rep(s, n)` | `string.rep("=", 5)` | `=====` |
| `string.format(modele, ...)` | `string.format("%.2f €", 3.5)` | `3.50 €` |

Les **marqueurs** de `string.format` : `%s` (texte), `%d` (entier), `%.2f` (décimal avec 2 chiffres après la virgule), `%5d` (entier sur 5 caractères, aligné à droite).

Raccourci : `("taxi"):upper()` équivaut à `string.upper("taxi")` (syntaxe avec `:`, expliquée au module B8).

<Encadre type="piege" titre="⚠️ Les accents">
`string.upper("é")` laisse `é` tel quel : les fonctions `string` de Lua traitent les octets, pas les lettres accentuées. Pour les noms affichés en majuscules, préfère des textes sans accents.
</Encadre>

## Erreurs fréquentes

| Message | Cause | Solution |
|---|---|---|
| `attempt to perform arithmetic on a string value (constant 'Total : ')` | `+` utilisé pour coller du texte | Utilise `..` |
| `attempt to concatenate a nil value (global 'nom')` | `..` avec une variable vide | Vérifie la variable (B1) |
| `attempt to compare number with string` | `5 < "10"` | Convertis avec `tonumber` |
| Affiche `2.4000000000000004` | Les décimaux sont approximatifs en informatique | `string.format("%.2f", x)` |

## Récapitulatif

- Calcul : `+ - * / // % ^`, parenthèses pour l'ordre. Comparaison : `== ~= < > <= >=` → booléen.
- Texte : `..` colle, `#` mesure, `tostring` / `tonumber` convertissent.
- `string.upper`, `lower`, `sub`, `rep`, et surtout `string.format("%s %d %.2f", ...)`.

## Je suis bloqué, que faire ?

Découpe : affiche chaque morceau séparément (`print(prix)`, `print(quantite)`) avant de les combiner. Pour `string.format`, vérifie que le nombre de `%` correspond au nombre de valeurs.
