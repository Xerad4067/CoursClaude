## Comment travailler

1. Dans ton dépôt : `mkdir parcours-b\b1` (un dossier par module).
2. Pour chaque exemple et exercice : crée le fichier, **tape le code toi-même** (pas de copier-coller : tes doigts apprennent aussi), exécute avec `lua fichier.lua`.
3. Compare avec le **résultat attendu**. Bloqué ? Ouvre les indices **un par un**.
4. En fin de séance : `git add`, `git commit`, `git push`.

<Encadre type="retenir">
Les solutions affichées sont **exactement** celles testées automatiquement (`lua exercices/tester.lua` dans le dépôt du cours). Si ta solution est différente mais affiche le bon résultat, elle est probablement juste aussi : il y a souvent plusieurs bonnes réponses.
