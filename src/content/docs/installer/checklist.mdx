Coche chaque point **après** avoir vu le résultat attendu. Les cases sont enregistrées dans ce navigateur (5 XP par case). Toutes les commandes ci-dessous sont en **lecture seule** : elles affichent des informations sans rien modifier. Elles sont issues de la documentation officielle mais **non testées sur Windows**.

<Encadre type="astuce" titre="💡 Tu veux mon avis sur ta machine ?">
Lance les commandes de la section « Connaître ta machine », copie le résultat (sélection puis `Ctrl+C`) et colle-le dans une conversation avec Claude ou dans ton journal. Ne colle jamais de mot de passe ni de jeton.
</Encadre>
